# 白玉京 · 凝影阁设计方案

这是面向日常分享、录屏归档的 Windows 本地视频压缩工具。操作围绕导入视频、选择预设、执行队列、查看结果展开。

参考 HandBrake 的预设与队列概念、Shutter Encoder 的本地 FFmpeg 工作流，自行实现界面与逻辑，不复制其代码。设计另参考 frontend-design、UI/UX Pro Max 的扁平工具型界面建议，以及用户指定的 benjitaylor/skills/stageshow。

UI/UX Pro Max 两次设计检索均返回了营销页布局，不能用于桌面工作台，因此布局采用自行设计的三栏工作区；其中的扁平风格、蓝色文件工具配色、键盘焦点和对比度建议适用。

色彩：背景 #F6F7FB，面板 #FFFFFF，正文 #202534，次级正文 #647084，操作蓝 #355BE8，成功绿 #18785D。字体为系统 Segoe UI / Microsoft YaHei UI，离线可用，数字启用等宽数字。

布局：左侧窄导航，中部导入区与文件队列，右侧固定参数面板；底部显示输出路径和执行操作。以文件缩略图与原始/输出体积对比作为主要视觉信息。避免营销式大标题、装饰性统计和多余渐变。
